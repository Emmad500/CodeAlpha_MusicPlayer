# 🎵 Music Player

A sleek and modern Music Player built with **HTML**, **CSS**, and **JavaScript**. This project features a beautiful user interface with a dark galaxy theme, vinyl-style animations, and essential music controls.

## ✨ Features

- **Play/Pause Control**: Toggle between playing and pausing tracks.
- **Next/Previous**: Skip to the next or previous song in the playlist.
- **Progress Bar**: Interactive progress bar to seek through the song.
- **Volume Control**: Adjust the volume with a slider.
- **Playlist**: View and select songs from a built-in playlist.
- **Animations**: Rotating vinyl animation when music is playing.
- **Responsive Design**: Looks great on desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5**: For the structure of the application.
- **CSS3**: For styling, gradients, and animations.
- **JavaScript (Vanilla)**: For logic, audio handling, and DOM manipulation.
- **FontAwesome**: For the icons used in the player.

## 🚀 How to Run

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/CodeAlpha_MusicPlayer.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd CodeAlpha_MusicPlayer
    ```
3.  **Open `index.html`**:
    - You can open the file directly in your browser.
    - Or use a live server extension in VS Code for a better experience.
